# Changelog

## 1.2.0 — Pick the export type first

- **Choose "Audio or video file" or "For phone" at the top.** "For phone" now shows only the preset picker; length, format, fades, video, info file and speed options appear only for a file export, where they apply.
- **Your choices are remembered.** Export type, length, format and fades stay as you left them for the next export.
- **The preset starts on the one loaded in the Mixer** each time you open the tab.

## 1.1.0 — Export for phone

- **New format: "For phone (Noctívago mobile)".** Saves a preset file for the Noctívago phone app, with every sound's Remix settings and all reverb baked in so the phone only mixes. Length, fades and video don't apply. Needs Noctívago 0.1.268 or newer.

## 1.0.0

- First release as its own plugin, moved out of the app.
